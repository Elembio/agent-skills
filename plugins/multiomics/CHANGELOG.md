# Changelog

Changes to the `multiomics` plugin. Each version matches the plugin version in `.claude-plugin/plugin.json`.

## v0.6.1

### New Features

- First public release of the multiomics skills: skills that guide an agent through Cytos analysis, from locating and loading a Spatial Data Object to quality control, normalization, clustering, differential expression, and the 3′ transcriptome, OPS, and imaging pipelines.
- Validated against `elembio-spatialdata-analysis` 0.16.0 or later.
